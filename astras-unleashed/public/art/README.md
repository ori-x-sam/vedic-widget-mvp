# Painted art

Drop the painted files here; the game picks them up at boot, and the placeholder draws until a file exists.
Prompts for every file are in `ASSETS.md` at the repo root.

- `cards/<card id>.png`: a god's card art, 5:7 (for example 1000 x 1400), the god breaking over the top edge.
- `units/<card id>.png`: a god's full-body arena figure, transparent background, facing the camera, feet at the bottom
  edge, about 512 px tall.

Card ids: ganesha hanuman narasimha vishnu kartikeya kali durga shiva agni yama surya rama vayu ganga parvati indra
saraswati lakshmi krishna brahma, and the token hamsa.
